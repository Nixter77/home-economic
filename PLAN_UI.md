# PLAN_UI.md — Заметки по UI

> Этот файл содержит идеи и решения по визуальной части.
> Реализуется **после** утверждения архитектурного плана.
> Стили строятся на основе [DESIGN.md](./DESIGN.md) (Flash design system).

---

## Общая концепция

- **Mobile-first** — основное использование: добавить расход с телефона после покупки.
- **Midnight тема по умолчанию** — приятнее для глаз, особенно при частом использовании.
- **Минимум кликов** — от открытия до записи расхода ≤ 3 касания.
- **Нижняя навигация** — 5 табов (Dashboard, Add, History, Analytics, Settings).

---

## Экраны — UI-заметки

### Dashboard
- Верхняя часть: крупная сумма расходов за текущий период (typography: `display`).
- Под ней: chip-переключатель периода (День / Неделя / Месяц / Всё).
- Блок графиков — в glass-card, по одному на карточку, вертикальный скролл.
- Pie chart — без легенды, лейблы прямо на секторах (чтобы занимал меньше места).
- Последние транзакции — компактный список под графиками.

### Add (Добавление)
- Экран открывается с фокусом на поле суммы.
- Категории отображаются как grid из emoji-кнопок (3 × N), выбранная подсвечивается `primary`.
- Большая кнопка «Сохранить» внизу экрана (button-primary, pill).
- После сохранения — лёгкая анимация (✓ check) и переход на dashboard.

### History
- Группировка по дням (заголовок «30 июля 2026» → карточки транзакций под ним).
- Каждая карточка: emoji категории слева → название + заметка → сумма справа.
- Свайп влево → действия (редактировать / удалить) — или длинное нажатие.
- Фильтры — выдвигаемая панель сверху.

### Analytics
- Селектор периода — такой же chip-бар, как на dashboard.
- Графики занимают бо́льшую часть экрана.
- Stacked bar chart — горизонтальный скролл для длинных периодов.
- Таблица «Сравнение месяцев» — горизонтально скроллится на мобиле.

### Categories
- Список с drag-and-drop для перестановки (приоритет).
- Цветовой индикатор слева от каждой категории.
- Добавление: inline-форма внизу списка.

### Settings
- Простой список переключателей.
- Экспорт/импорт — кнопки с иконками файла.
- «Сброс всех данных» — красная кнопка, два подтверждения.

## Анимации

- Переходы между экранами: fade + лёгкий slide (150ms, ease-out).
- Графики: Chart.js встроенная анимация при загрузке (400ms).
- Добавление транзакции: checkmark animation (300ms).
- Удаление: collapse карточки (200ms).
- Все анимации отключаются при `prefers-reduced-motion: reduce`.

## Адаптивность

| Breakpoint | Layout |
|------------|--------|
| < 768px | Одноколоночный, нижняя навигация, full-width карточки |
| ≥ 768px | Sidebar навигация слева, 2-колоночный layout на dashboard |
| ≥ 1200px | Sidebar + 3-колоночный grid аналитики |
